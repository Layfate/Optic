# Optic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Optic as a working native Roblox Studio performance investigation plugin and improve the original implementation prompt.

**Architecture:** Focused Luau modules separate pure diagnostics and analysis from Roblox service adapters and native UI. A dependency-free Node builder emits an installable XML model and a standalone plugin script. Behavioral tests execute production Luau through WASM.

**Tech Stack:** Luau, Roblox Studio plugin APIs, Node.js, luau-web (development only).

**Spec:** `docs/superpowers/specs/2026-11-14-optic-design.md`

## Global Constraints
- No fake measurements, source mutations, networking, injected runtime agents or per-script memory claims.
- 0.5-second sampling; 120 retained samples; 15-second CPU capture and 8-second response timeout.
- 2,000 scripts / 256 KiB per source / 500 findings, yielding every 20 candidates; show partial coverage.
- All owned resources must clean up; capture cannot outlive Play mode or plugin unload.
- Deliver files directly in the user's Optic folder; no existing repository or worktree exists.

## Review Focus
- Comments, quoted/long strings and nested blocks: scanner must retain correct lines and avoid false code matches.
- Unavailable permissions and services: preserve a useful panel and explicit unavailable statuses.
- Stop, hide, unload and late profiler replies: no leaked listeners, revived capture, or stopping someone else's capture.
- Malformed/empty profiler data and missing fields: no crashes, double-counted total CPU, or fabricated results.
- Large projects and report payloads: bound work and display explicit truncation and coverage.
